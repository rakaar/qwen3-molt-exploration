Transfer the eleventh-month signal into the fifth-month prompt

Two experiments on L29–T2375: copy the donor’s scalar gate alone, then copy its gate and operator UVx. Both edit only the recipient’s final input token is, position 6. Generated tokens receive no edits.

Donor · native answer Novemberthe eleventh month of the year is

Final input position 7 · natural gate 1.158554.

Recipient · native answer Maythe fifth month of the year is

Final input position 6 · natural gate 0. The marked token is the only edited position.

Neither unamplified copy changes May to November. Larger gates can make the completion start with November, followed by an explicit correction back to May. The recorded continuations matter: these are initial-answer effects, without a stable November-only answer.

Exact intervention, controls, precision, and limits

The gate-only experiment retains the fifth prompt’s own operator. The full-copy experiment freezes UVx from the donor’s unmodified final input token and replaces only this MOLT’s contribution. The rest of the recipient’s native MLP output remains.

Gate only:
  edited MLP5 = native MLP5 + (g − φ5) × UVx5

Gate + donor operator:
  edited MLP5 = native MLP5 − φ5 × UVx5 + g × UVx11

φ5 = natural recipient gate = 0
g = fixed scalar from the strength table
UVx5 = recipient operator; UVx11 = frozen donor operator
Selected input: position 6, " is"; no generated positions edited

Edits use FP32 and one BF16 cast. The patch retains the MOLT input/output standardizers and has no extra RMSNorm or vocabulary projection. The model then completes its normal forward pass. At g = 1.1585536003112793, the full inserted vector matches the saved natural donor contribution exactly.

Pinned native Qwen3-4B; raw lowercase completion prefixes; greedy decoding; eager attention; TF32 off; 32 generated-token limit. All primary sweep continuations reached that limit, including the native baseline. The first 12 native tokens reproduce earlier records.

Native/observer and zero controls match exactly. CPU audits reconstruct gates, operators, selected-position masks, the exact BF16 edits, and next-token probabilities. The scalar-copy control reproduces the preceding scalar experiment. The full-copy natural value, first initial-November value, and maximum value repeat exactly. A separate scalar follow-up reloaded the model and reproduced gates 0, 1.158554, and 20 exactly.

The strength grid is exploratory and deterministic. The first successful value tested is not a global minimum. Equal-norm controls match intended contributions before BF16 rounding; actual rounded edit norms are retained in the source records. These results cover one recipient prompt, not broad ordinal transfer.
