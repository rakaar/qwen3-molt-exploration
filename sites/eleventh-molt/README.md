It includes leading space and case, excludes following punctuation/end tokens, and does not sum over alternate renderings. Roman xii uses two tokens. Full continuations, natural subsequent gate activity, and unobserved final-token gates are retained.

Geometry compares original gate-times-operator contributions at each prompt’s final input token, before final RMSNorm or vocabulary readout, in native MLP-output units.
