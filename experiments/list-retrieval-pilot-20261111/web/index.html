Measurement, controls and source data

The native BF16 Qwen3-4B remains intact. A returning-None observer reads the residual before layer 29’s post-attention RMSNorm. It applies the saved input standardizer and computes the scalar JumpReLU gate in FP32. Layer and transform IDs are zero-based.

Each baseline is repeated with the passive observer. Generated IDs, selected probabilities, every decoding-logit hash and the final unused-logit hash must agree exactly. No gates, contributions, attention or MLP outputs are changed.

Each generated word token is traced when it becomes the next forward pass’s input. One extra read-only pass traces the final generated token (normally EOS); it generates no further token. That terminal trace is flagged in the raw data and token tooltips.

Primary accuracy requires a complete, word-only answer after case and punctuation normalization, with a 32-token limit. A separate first-listed-word score retains semantically relevant answers with extra text. Prompt layouts and word orders were frozen before the model ran.

The query contains the fixed instruction “starting from 1”. Removing that numerical cue is an untested follow-up. Its presence limits what question-region activation alone tells us about list indexing.
