# Publish the original privacy zero-clamp results

The output-only three-arm experiment and the follow-up three-timing comparison are preserved in their original dated result folders. All recorded answers remain exact native refusals. Frozen protocols, executed runners, complete responses and numerical traces are unchanged.

`build.py` checks saved results and executed-source hashes, adds report navigation and a dated publication note, and generates report checksums. Run from the repository root after copying the original science files into the publishing checkout. `verify.py` in each original result folder checks the scientific records independently.

The scientific inference dates are 15 October. Publication is 20 October. Neither this script nor publication performs inference or a GPU lifecycle action. These negative results use one Bob/Alice prompt; the separate positive API-key study uses a different prompt template.
