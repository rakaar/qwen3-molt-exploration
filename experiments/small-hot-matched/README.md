# Matched small-to-hot experiment — 10 October 2026

Original executed scientific code for comparing transcoder contribution edits with MOLT full-contribution and scalar-gate edits. The saved run contains 205 intervention trials and 78 generations. [Saved results](../../results/2026-10-10-small-hot-matched/artifacts/results.json), [tensor audit](../../results/2026-10-10-small-hot-matched/artifacts/verification.json), and [interactive report](https://small-hot-molt-experiment.rakaar.chatgpt.site/) accompany this code.

Receiver: `What is the opposite of "small"? Reply with only the word, nothing else.`

Donor: `What is the opposite of "hot"? Reply with only the word, nothing else.`

The primary edit is at operand token position 9, with zero-based indexing including the chat template. `constrained` freezes the reference attention patterns and pins MLP outputs through the edited region. `propagated` uses native forward execution with additive edits and freely recomputed attention. Read the `protocol` field in each result row when comparing outcomes. MOLT full edits transfer gate × low-rank output; gate-only edits retain the receiver low-rank output.

## Reproduce

Use Python 3.12 and install a CUDA-enabled PyTorch build appropriate for the GPU, then install `requirements.txt` in this directory. The recorded run used an RTX 3090, PyTorch `2.14.0+cu130`, and Transformers `4.57.6`; different runtimes can change the last probability digits.

From the repository root:

```sh
python3 -m pip install -r experiments/small-hot-matched/requirements.txt
python3 experiments/small-hot-matched/fetch_transcoder_assets.py
python3 experiments/small-hot-matched/prepare.py
python3 experiments/small-hot-matched/run_experiment.py
python3 experiments/small-hot-matched/verify.py
python3 experiments/small-hot-matched/complete_probe_answers.py
```

Preparation downloads the pinned base model, full MOLT layer 22, and selected MOLT tensors for the other intervention layers. Model weights are ignored by Git. `fetch_transcoder_assets.py` regenerates the small selected transcoder encoder/decoder/bias row files and verifies their original SHA-256 hashes. The upstream normalization/gating code and its license notices are retained.

`bootstrap.sh` and `execute_after_prepare.sh` preserve the original Vast container paths; use the portable commands above outside that layout. No cloud account keys, SSH transport records, or GPU provisioning commands are included. Provision and close any future GPU separately.

Results generated by these commands appear in this experiment directory's `artifacts/`. The dated `results/` directory is the immutable measurement snapshot. The original runner was verified on the GPU; the added asset-rebuild helper is CPU-only preparation, and the complete packaged experiment has not been rerun on a new GPU.
