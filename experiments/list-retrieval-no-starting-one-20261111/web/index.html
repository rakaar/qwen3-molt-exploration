Measurement, controls and source data

All 30 original cases are matched by ID and order. The revised prompt deletes only the exact substring starting from 1, including its leading space, and retains the period. Word orders, formats, requested positions, native BF16 checkpoint, tokenizer, thinking-disabled chat template, greedy decoding and 32-token limit are unchanged.

In the original/revised prompt comparison, a passive observer reads the residual before layer 29’s post-attention RMSNorm, applies the saved MOLT input standardizer, and measures T2375’s scalar JumpReLU gate in FP32. It returns no replacement. Native attention and MLPs run normally; no gate, contribution or residual is edited. Layer and transform IDs are zero-based.

Each generated token is measured when it is subsequently processed. A final read-only forward traces the last generated token (normally EOS), without generating another token. Full traces retain the chat wrapper, answer prefix and terminal token.

Primary accuracy requires an EOS-terminated word-only response after case and punctuation normalization. A separate first-listed-word score counts “12. hammer” as containing the right first word, with extra text. These selected, repeated lists are a pilot, not a broad retrieval benchmark.

Persistent activation in the answer prefix is correlational evidence about prompt context. It does not establish that T2375 selects an array element. The printed 11. remains present in numbered lists; bullet lists provide the matching unnumbered condition.
