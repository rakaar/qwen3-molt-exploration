# Abstention experiment directory

One table of descriptions and report/source links for the Qwen3-4B MOLT abstention experiments and related native confidence/uncertainty gate studies. Includes negative results and the early qualification/refusal studies.

Edit `catalog.json`, then run `python3 experiments/abstention-index/build.py` from the repository root. The builder checks the local targets and writes `results/abstention/index.html` and its downloadable catalog. Browser-check the table, search and desktop/mobile layout before publishing.

This directory summarizes saved reports and performs no model inference. Overlapping cohorts are not independent replications. The completed twenty-question comparison takes precedence over earlier incomplete grids; fixed absolute gate replacement and additive low-rank contribution steering are separate methods.
