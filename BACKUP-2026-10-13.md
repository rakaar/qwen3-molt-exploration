# October 12-13 experiment backup

This backup adds three completed experiments to the existing October 10-11 results:

- `experiments/residual-similarity/` and `results/2026-10-12-residual-similarity/`: 72 transcoder strengths compared with fixed MOLT strength 4.5, with full next-token logits and token-9 residual vectors.
- `experiments/spider-ant/` and `results/2026-10-12-spider-ant/`: 927 main trials and 60 follow-up controls across eight selected MOLTs, including the L8-T2201 implicit donor patch and L3-T2309 explicit prompt diagnostic.
- `experiments/explicit-ant-implicit-spider/` and `results/2026-10-13-explicit-ant-implicit-spider/`: 44 main trials and 16 controls with L3-T2309, explicit ant donor token 8 and implicit web-weaving receiver token 12. At 24x, P(next token = 6) is 99.997842%; at 32x it is 99.999976%. 24x is the lowest successful tested strength; no strengths between 16x and 24x were tested.

The backup includes the exact scientific runners, controls, pinned preparation code, protocols, full-vocabulary logits, baseline captures, intervention vectors, selected assets required for the residual comparison and cross-prompt verifier, independent verification records, reports, figures, and explanatory images with their generation prompts. The eight selected dashboard feature records and six activation-example files are preserved under `comparisons/2026-10-12-spider-ant/`. The activation examples use lossless gzip compression, with original and compressed hashes in `compressed-evidence-manifest.json`; the selected summaries have their own manifest. Unrelated dashboard feature records and service configuration are omitted.

The 263,726,186-byte spider/ant logits file is split into four raw-byte chunks so that each Git object stays below GitHub's per-file limit. Reassembly reproduces the exact original file and checksum; it does not change tensor values or the saved experiment checksums.

## Verify a fresh clone

From the repository root:

```sh
python3 verify_oct12_13_backup.py
python3 restore_large_files.py
python3 experiments/residual-similarity/verify.py results/2026-10-12-residual-similarity
python3 experiments/spider-ant/verify.py results/2026-10-12-spider-ant
python3 experiments/explicit-ant-implicit-spider/verify.py results/2026-10-13-explicit-ant-implicit-spider
```

The manifest and restore helpers use only Python's standard library. Scientific audits additionally require NumPy. They recompute probabilities and geometry from the saved tensors and verify the executed runner hashes. Inference is unnecessary for the backup audit.

Base-model weights, duplicate export/source archives, temporary provider/SSH transport records, account credentials, account balance snapshots and cache files are retained locally or can be regenerated from pinned public sources. They are not part of this GitHub backup. The published reports link to the preserved scientific source directories. Historical cleanup records show the original Vast instances and storage were deleted after verified local backups; no GPU is rented for this publication.

These are prompt-specific exploratory steering measurements. High next-token probability does not establish general task accuracy or semantic concept replacement. The complete sweep and controls include failed conditions, inactive interventions and the decrease in P(6) at excessive strengths.
