Does the eleven effect follow?

Both eligible codebooks keep the correct eleventh-month codeword after all active input contributions are removed. The gate still activates, but neither answer switches to the December codeword.

Matched month-name chat controls also keep November, while December gains probability. The absence of a greedy answer flip alone does not isolate a codeword-specific effect.

Five fixed, randomly shuffled codebooks assign a distinct word to every month. November and December receive different codewords in every mapping. The codebook line order is shuffled too. We ask for the eleventh and twelfth month in both completion and chat formats, freeze native results, then ablate only pairs that pass both native codeword checks.

Matched chat controls: month names also stay unchanged

Added after the initial pilot, before inspecting these control outcomes: use the same two codebooks but request the month name, plus a plain month-name chat prompt. All six native ordinal checks pass. Removing all positive input contributions leaves the November/December response text unchanged in every control. For all three eleventh-month controls, however, December gains probability: for example, 0.247256% → 3.732597% in the same-codebook-4 control. This differs from the very small codeword probability changes above. Natural contribution sizes and directions differ across prompts; these are not magnitude-matched interventions.

What this pilot establishes

T2375 can activate on eleventh-month questions even when the correct next answer is an arbitrary codeword. Activation is therefore not confined to cases whose response literally starts with November or eleven. In the two native-competent codebooks, removing all its positive input contributions does not reproduce the uncoded November-to-December effect. The matched month-name chat controls also retain their greedy answers, while their probabilities move toward December. An absent answer flip alone therefore does not isolate recoding, although the probability effects differ. This does not establish an abstract index operator, nor rule out context-dependent eleven-related support.

Limitations: two eligible codebooks; completion-format failures; the successful raw-completion reference differs from the working chat cases; no matched active-transform specificity controls in this pilot. No new codebooks were chosen after seeing ablation outcomes.

Method, audits and frozen records

Native Qwen3-4B BF16; pinned model revision 1cfa9a7208912126459214e8b04321603b3df60c, pinned MOLT revision 081ce901b090b64aeecf9bc8709b57c10411e32a. Greedy decoding, chat thinking off, 32-token generation limit, eager attention, TF32 disabled. The MOLT observer sees the L29 post-attention residual before native RMSNorm. Standardize it with the checkpoint’s input mean/std, apply the natural JumpReLU gate, and form the native-unit operator using the saved output std.

Only T2375’s natural gate × operator is subtracted from the native L29 MLP output; the edit uses FP32 and one BF16 cast. Native later layers run normally. All native/zero outputs and probabilities match exactly. Native eligibility was hash-locked before any nonzero edit. Independent CPU checks verify selected positions, gates, operators, probabilities and exact BF16 rounding at 30 saved vector positions. Across primary-pilot interventions, 8 positive input contributions were removed and zero generated positions edited. Ten primary-pilot scope runs target only zero gates and are explicitly identified as no-ops. The additional matched-control phase independently verifies 41 vector positions, removes 15 positive input contributions, and has 9 zero-gate scope runs.

Probability variants are encoded as output-token continuations from the fixed supplied prefix; the input is never retokenized. The report sums only the prescribed nonoverlapping token sequences, not every tokenization or phrasing that could express a codeword.
