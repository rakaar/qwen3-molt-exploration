CH probe: dataset and held-out validation

Qwen3-4B · layer 3 native MLP output · input word token · 19 October 2026

The probe learns a CH signal overall (test AUROC 0.9621), but fails on the reserved child cases. It is not validated for the intended Child-MOLT analysis.

The exact unindented child token receives probe output fewshot_upper: 0.00728, fewshot_lower: 0.00422, both below the frozen threshold 0.21350. It also misses chin. These are diagnostic failures, not evidence that CH information is absent from the model or from a MOLT. The probe has not been retrained to correct these selected cases.

A linear logistic-regression readout predicts whether a complete single-token dictionary word starts with CH, ignoring capitalization. It receives the 2,560-dimensional native layer-3 MLP output at that word. Neither MOLT activations nor the target answer are probe inputs. The model is unmodified.

Training and model selection

L2-regularized logistic regression; equal total class weight and equal family weight within a class. Centering and one global RMS scale are fitted on training data only. No per-coordinate scaling changes the meaning of Euclidean angles. Seven regularization values are compared on validation AUROC; ties prefer stronger regularization. The classification threshold maximizes validation balanced accuracy, with ties preferring proximity to 0.5.

Selected C: 0.01 · frozen threshold: 0.21349824987526578. The selected probe and threshold were saved before test scoring. Portable coefficients are saved in native raw-MLP coordinates.

Errors and limits

Held-out main-set errors: 72 prompt examples involving 27 distinct words: achievable, achieve, achieved, achievement, achievements, achieves, cabin, cabins, capitol, central, centralized, cheat, chef, chefs, climate, evaluation, glitch, glitches, happened, happening, happens, headline, headlines, here, preaching, premiere, rich.

The test set contains only 16 CH-positive stem groups, so the intervals matter. Multiple capitalization, whitespace and prompt variants are correlated; the primary metrics and bootstrap account for this by grouping them. Snowball stemming is a reproducible approximation to word families, not a guarantee of semantic or irregular morphological independence. The single-token dictionary restriction limits generalization to multi-token words and arbitrary spellings.

The diagnostic set contains words selected during our earlier investigation; it is kept separate from the randomly held-out test. The probe is a linear readout trained with class balancing, so its probabilities are not calibrated for natural text prevalence. Strong classification does not establish that the model uses this direction or that a MOLT has absorbed it. No MOLT alignment, component ablation or later-layer tracking was performed here.

Activation and result verification

The initial batch-32 extraction failed its predeclared single-prompt native-reference check (1.56% relative difference on one audit vector) and was rejected before fitting. The accepted extraction uses batch size one; early-stop collection exactly matches complete native forwards on all audit examples. The frozen dataset hash stayed identical. Saved predictions, preprocessing conversion, and held-out AUROC/balanced-accuracy/F1 were independently recomputed from the portable weights and exact BF16 activation bits.
