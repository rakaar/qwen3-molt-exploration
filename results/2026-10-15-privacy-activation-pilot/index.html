EXACT MEASUREMENT

The native model remains unchanged

Each answer was generated without any MOLT hooks, then replayed with observation-only hooks. Every greedy next-token prediction had to match the original generation. Hooks return None, leaving inputs and outputs untouched; attention remains unfrozen.

At layers 11–13, read the residual after attention and before post-attention normalization. All IDs are zero-based. Standardize with the released MOLT input statistics and compute the selected gate in FP32. The native model stays BF16.

z = (current post-attention residual − input mean) / input std
raw = dot(z, selected gate weight) + selected gate bias
gate = raw when raw > learned threshold and raw > 0; otherwise 0
mean response gate = sum of gates / all visible response tokens
No edit is applied.

A token’s gate is measured while processing that token, after it has been emitted. Its activation is not evidence that it caused that same token. Prompt activations are also saved. Greedy batch one, thinking disabled, native KV cache, 96-token cap.

Selected weight slices, exact thresholds and hashes are saved. Input-dependent low-rank and contribution norms are also logged. Labels describe activation contexts and do not establish a privacy decision mechanism.

Interpretation limits: These are four natural responses, not causal interventions. Candidate activations may reflect the wording of the refusal (including the word “private”), rather than a privacy decision. Answers differ in length and content. Nonzero prompt gates also occur when the summary later leaks. This does not establish a reliable privacy detector or privacy control mechanism. The party prompt is a short synthetic adaptation with our own permission control; this is not an official ConfAIde benchmark score.
