What was measured

The native model generated each answer without hooks. An observation-only replay then measured the residual entering layer 19’s post-attention layer normalization. Every next-token argmax was checked against the native generation. The native MLP and attention were unchanged.

After released input standardization, raw = z dot e_368 + bias_368. The gate equals raw only when raw > 0.56749147 and raw > 0; otherwise it is zero. Model computation is BF16 and gate math is FP32.

A box records activation while processing the displayed token. It does not show the activation that predicted that token. Means include inactive tokens and exclude EOS/special tokens; EOS is preserved in the raw data. Generation uses one user message, no system message, thinking disabled, greedy decoding, seed 0 and a 192-token cap.

Interpretation: activity in these examples can show that this gate is shared across refusal contexts. It does not show that the transform causes the refusal, that all safety refusals use it, or that a single mechanism explains the different contexts. No literature-novelty claim is made from this pilot. Response review was by Codex with prompts visible.
