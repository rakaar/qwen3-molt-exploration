observation

Alphabet examples reveal before-K down and before-L up

Three gates with before-K examples weaken; two with before-L examples strengthen. Roman examples suggest broader numeral/X/I contexts, without clear XII specificity.

Original report 1

Activating examples of changed alphabet and Roman gates

Alphabet: a coherent before-K down / before-L up pattern is visible in the examples. L33-T14, L34-T965 and L35-T760 weaken or turn off; L34-T1440 and L35-T2117 strengthen. These activation observations are candidates for causal tests, not a demonstrated mechanism.

All 13 on/off switches in alphabet/Roman plus the top three absolute continuously-active gate changes per prompt, excluding L34-T1468 already inspected separately.

Authenticated original dashboard: all 12 strongest, 6 medium and 6 lower-strength displayed windows per feature.

Square brackets mark the active token. Following token strings/IDs are recorded separately. Gate strengths in examples are rounded dashboard values.

Roman: broader numeral-format leads. L35-T1221 has X and I/i code contexts (and a Y counterexample); L35-T111 precedes several Roman numerals as well as dates. No comparably clean XI-versus-XII separation was found in the displayed examples.

Shared numerical lead: L33-T587 peaks before Twelve and 12, with clear 11/13 counterexamples. Its gate rises in both alphabet and Roman prompts, but falls in the month prompt, so it is not established as a general twelve feature.

What remains to test

The clearest alphabet follow-ups would preserve the native contributions of the K-related gates during T2375 ablation, or remove the L-related contributions individually. Roman candidates and the shared numerical T587 remain less specific. None of these causal follow-ups was performed here.

The earlier failed T1468 rescue does not rule out these distinct candidates or combinations of them.

Limits

  • Displayed examples are a selected subset of a ten-million-token corpus, not an exhaustive selectivity test.
  • Before-K/L includes word fragments and case/whitespace variants; it is not a claim that every example predicts the exact answer BPE token.
  • Medium/lower windows for several features repeat chat-start markers and add limited semantic diversity.
  • These MOLT gates are diagnostics on native states; neither examples nor gate-value shifts establish a causal contribution direction.
  • No causal tests were run on these new candidates. Existing T1468 negative ablation/rescue results do not rule out these other features.

Validation: 19 features, 456 displayed windows, 13921 tooltip token records; all source identities, contiguous coordinates and label matches verified.
