What was edited, checks and downloads

At layer 29, every supplied input token receives (fixed gate − natural gate) × recipient operator, added to the native MLP output. This includes the initial chat wrapper, list, question, and complete assistant prefix. The recipient operator is ((x − input_mean) / input_std) @ V @ U × output_std. The native model otherwise runs normally. No generated, teacher-forced candidate or terminal token is edited.

Gate 2 can reduce a few natural gates slightly above 2; it is absolute replacement. The selected positions cover all 13,580 input positions across the edited runs, with positive measured changes at every position. All 20 native replays and zero-strength controls exactly match the saved baseline. Gates/operators and BF16 rounding were independently reconstructed at 840 predetermined vector samples; all-position gate and contribution norms are retained. Greedy generation, thinking off, 32-token limit.

Prompt-level follow-up counts cannot be directly compared with pilot counts: they use different word orders and baseline competence varies. This experiment supplies no evidence that this edit implements general eleventh-item lookup.
