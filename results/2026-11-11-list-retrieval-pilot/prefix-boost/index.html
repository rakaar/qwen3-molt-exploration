Scope, validation and data

Both input-prefix newline tokens receive the same fixed scalar: after <|im_end|> and after </think>. The local recipient operator is retained. The native MLP output receives (target − natural gate) × operator; this is absolute gate replacement, including when the natural gate was zero.

List-reading tokens and all generated tokens are unedited. Each of the 100 variants edits exactly two input positions. All 20 native and zero-strength runs exactly match the saved baselines. Independent CPU gate/operator reconstruction and exact BF16 output-rounding checks passed. No run hit the 32-token generation limit.

For the sentence-form ring response, the exact generated token-sequence probability (including its selected EOS) was 7.1099%. Direct “ring” at response start was 0.002327%; it does not include the sentence form.

Native requested-word correctness and saved native eleventh-word control correctness are shown separately. None of the nine cases passing both controls newly answered item 11. Natural recipient gates at the selected positions ranged from 0 to about 0.896; targets were 2–40. These are exploratory high-gain edits, not a proof of an array-indexing mechanism.
