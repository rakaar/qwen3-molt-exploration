Method & source data

Natural activations, native model

All examples are raw completion prefixes. The final input position predicts the first generated token. The observer reads the L29 residual after attention and before post-attention layer normalization; it computes the released MOLT’s standardized gate and operator, and leaves native computation unchanged.

The three original anchors reproduce exactly. All 36 runs preserve native generated IDs and measured next-token logits with the observer attached. Independent CPU vector audits and both backup hash checks passed.
